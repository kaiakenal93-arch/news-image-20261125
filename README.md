Sum up 25 November's world news in one image — make.fun bounty entry.

`main.ts` (Node 22, standard library only) draws one 1024×1024 PNG of the day's news: 50 stories — 3 heroes (US tariffs, Cairo tanker fire, Shenzhou-24), 6 mids, 41 briefs — with a CLAIMED vs CONFIRMED honesty box, a date check, and a markets strip.
